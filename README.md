# Memos M

An unofficial third-party Android client for [Memos](https://usememos.com/).

This app exists because the official MoeMemos Android client currently has serious usability issues on Android, making it difficult to use in day-to-day workflows. This project aims to provide a more reliable and responsive option while staying compatible with the Memos backend.

## Project Goals

- Be a lightweight, fast Android client for Memos.
- Focus on a smooth mobile experience first.
- Remain independent from the official client while staying protocol-compatible.

## Key Differences from MoeMemos

- **Partial syncing**: Unlike MoeMemos, this client does not always attempt to fully sync everything, which makes it significantly faster in practice, especially on slower networks or large accounts.

## Status

This project is still a work in progress and is missing many features you may expect from a full Memos client.

- Expect breaking changes and rough edges.
- Some core Memos features are not implemented yet.

Despite that, the app is already usable for basic workflows, and feedback is very welcome.
